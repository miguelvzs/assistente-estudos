# Interface básica
Uma coluna, título, aviso de estado da integração, três botões e resultado.
Verde escuro nos controles, fundo claro, texto Arial. Foco de teclado visível,
role alert para erro, aria-live para resultado. No celular, botões ocupam a largura.

Sem mascote OpenAI, balões de conversa ou elementos que sugiram respostas de IA.
A indicação de demonstração/pendência permanece visível. O JSON local é exemplo;
não mostrar notas ou horários fictícios como se fossem informações institucionais.

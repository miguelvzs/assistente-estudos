JSON.stringify é operação JavaScript para mostrar o objeto como texto, explicada
no guia. import.meta.env.MODE é configuração do Vite. Não há novos hooks, biblioteca
visual ou backend. OAuth/CORS e APIs acadêmicas não estão implementados nem atribuídos
às aulas. As fontes curriculares são as aulas do curso Moodle 587, consultadas na
preparação original. A base mantém o mínimo necessário, não todos os tópicos.

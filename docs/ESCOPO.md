# Escopo SUAP
Pedido em 13/11/2026: alternativa básica em outra branch, separada da OpenAI e
documentada para explicação. Interface: consultas por botões, carregamento, resultado
e erro. Tecnologias mínimas das aulas React, CSS e Axios GET.

Excluído: IA, chat, backend, armazenamento de dados pessoais, senha no app e tokens
em arquivos públicos. A demonstração local é ferramenta didática, não API SUAP.

Aberto: documentação oficial da API acadêmica IFSP, rotas de consulta, formato JSON,
cadastro do aplicativo, autorização do aluno e CORS. Não presumir que a API do IFRN
é igual à do IFSP. Essas pendências bloqueiam integração real e entrega desta versão
como consumo de API institucional. Não bloqueiam o estudo da interface.

Submissão Moodle adiada pelo usuário. Não enviar a base como trabalho concluído.
